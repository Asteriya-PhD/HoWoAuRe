# 作业扫码登记

把「收作业→对名单」变成「镜头扫过去」。全班作业本的二维码朝上摊开，手机/平板镜头从左往右扫一遍——哪本入镜哪本就登记，电脑大屏实时刷新已交/未交名单，然后按扫码顺序快速批改打等级（等级表可自定义，比如 A+ / A / A- / 不合格）。

**纯局域网运行**：不需要云服务器、不需要账号、不需要外网，数据全部存在自己电脑里。

- ✅ 一键装机：macOS 双击安装，Windows 解压即用，都不用装任何环境
- ✅ 收作业像拍照一样快：一帧多个码同时登记、重复扫不重复记、截止后再扫自动记补交
- ✅ 批改像翻本子一样顺：作业堆叠顺序 = 扫码顺序，键盘 1~4 逐本打等级
- ✅ 数据自己掌控：导出备份就是一份文件，换电脑、发同事都方便

## 一、下载安装

到本页右侧 **Releases** 下载安装包（两个版本任选）：

### 🍎 macOS

1. 下载 **`作业扫码登记_1.0.0_aarch64.dmg`**，双击打开
2. 把 **作业扫码登记.app** 拖进「应用程序」文件夹
3. 首次打开：在启动台点开 App，如提示「无法验证开发者」——右键 App →「打开」→ 再点「打开」（只提示这一次）
4. 第一次如弹出防火墙提示「是否接受传入网络连接」，点「允许」（手机扫码需要）

### 🪟 Windows

1. 下载 **`作业扫码登记_Windows免安装版.zip`**（约 42MB）
2. 解压到任意文件夹，比如桌面或 D 盘（整个文件夹以后就是软件本体，数据也存里面）
3. 双击文件夹里的 **`启动作业扫码.bat`**——不需要装 Node.js、不需要联网
4. 首次运行如弹出防火墙提示，点「允许访问」

> 💡 以后想升级版本：重新下载新包，按同样方式覆盖即可；你的作业数据存在单独的数据文件夹里，不受影响。

## 二、开始使用（每学期/每天 5 步）

1. **建名单**：设置 → 班级名单 → 新建班级 → 导入 Excel/CSV（需有「姓名」列，学号可选）
2. **打贴纸**：设置 → 二维码 → 选排版 → 生成 A4 PDF → 打印（建议不干胶贴纸）贴到作业本封面右上角。**一次打印，用一学期**
3. **收作业**：工作台 → 点选班级 → 填科目和作业标题 → 「开始收作业」→ 电脑上出现一个大二维码
4. **扫码登记**：手机连**同一个 WiFi**，扫电脑上的码打开扫码页 → 允许摄像头 → 点「开始连续扫码」，镜头匀速从作业本上扫过即可
   - 本子**单层摊开**别叠压；识别成功"叮"一声变绿；底部有补光灯、变焦、广角预览按钮
   - 个别码扫不进：凑近单扫，或点「未交 N 人」按名字手动登记
   - 点「截止收集」后，再扫的码自动记为**补交**
5. **批改与查看**：
   - 批改页：按作业堆叠顺序，键盘 <kbd>1</kbd>~<kbd>4</kbd> 依次打等级，<kbd>Ctrl+Z</kbd> 撤销，支持勾选批量
   - 历史 → **班级视角**：一张表看全班每次作业谁交谁缺、得了什么等级
   - 历史 → **学生视角**：搜任意学生的名字，看 TA 全学期的作业记录
   - 一键复制未交名单（发家长群格式）或导出 Excel

## 三、手机首次打开提示「不安全」

浏览器规定：**摄像头只能在 HTTPS 页面使用**。本系统在电脑上自动生成了专属证书，手机首次打开会提示"证书不受信任"，属正常现象，一次性放行即可：

- **iPhone (Safari)**：提示页点「显示详细信息」→「访问此网站」（部分版本需输密码）
- **Android (Chrome)**：点「高级」→「继续前往 …（不安全）」

之后正常使用。换 WiFi 导致电脑 IP 变化时证书会自动更新，重做一次上面的放行即可。

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 手机扫了码但打不开页面 | 确认手机和电脑连**同一个 WiFi**；部分校园网开了「设备隔离」，改用电脑开热点让手机连 |
| 点开始扫码黑屏/没反应 | 手机上地址必须以 `https://` 开头（从电脑上的二维码扫入不会错）；浏览器设置里允许该网站使用摄像头 |
| 相机一直"正在打开摄像头…" | 完全关闭标签页重开；还不行就重启手机浏览器 |
| 个别码扫不出来 | ① 凑近单扫 ② 展开「未交 N 人」按名字手动登记；🐞 抓帧诊断可看识别引擎实际结果 |
| 识别慢 | 光线充足更快；扫动**中速**（太快会运动模糊）；码与码之间留空隙 |
| 打印的码识别率低 | 打印选「实际大小/100%」不要「适应页面」；码四周 4mm 内别贴文字图案 |
| 扫码没声音 | 手机侧边静音键会静音网页声音，识别时画面也会变绿提示 |
| 想更新到新版 | macOS：下载新 DMG 覆盖安装；Windows：解压新包后把旧文件夹里的 `data` 文件夹拷进新文件夹。**数据不会丢** |
| 想清空全部数据 | macOS：删除数据文件夹里的 `db.json`（菜单「打开数据文件夹」可直达）；Windows：删除包内 `data` 文件夹 |

## 五、数据与备份

- 所有数据（名单、记录、等级设置）都存在**本机**，不经过任何服务器
- 设置 → 数据备份 → **导出备份**，存好这个文件；换电脑/重装系统后「导入备份」即可完整还原，**二维码贴纸继续有效**，不用重贴
- Windows 免安装包：整个文件夹拷到 U 盘/换电脑，数据跟着走
- 程序每次启动还会自动留最近 20 份快照（数据文件夹的 `backups/` 里），手滑有救

## 七、给开发者

技术栈与目录说明见 [AGENTS.md](AGENTS.md)。核心：Node.js + Express 单文件服务端（`server.js`）+ Vue 3 无构建前端（`public/`，全离线本地化）+ Tauri 2 macOS 壳。开发调试用 `npm start`（需 Node.js 18+），打包 macOS 用 `cargo tauri build`，Windows 免安装包用 `node scripts/make-win-portable.mjs`。数据为单文件 JSON，含隐私内容已 gitignore。
