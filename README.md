# 作业扫码登记

把「收作业→对名单」变成「镜头扫过去」。全班作业本的二维码朝上摊开，手机/平板镜头从左往右扫一遍——哪本入镜哪本就登记，电脑大屏实时刷新已交/未交名单，并支持按扫码顺序快速打等级（A+ / A / A- / 不合格）。

**纯局域网运行**：不需要云服务器、不需要账号、数据全部存在电脑本地，学校没外网也能用。

## 〇、macOS App 版（推荐日常使用）

不想装 Node.js、不想开终端？直接用打包好的桌面 App（Tauri 壳 + 内置 Node 运行时，双击即用）：

1. 打开 `src-tauri/target/release/bundle/dmg/` 里的 **`作业扫码登记_1.0.0_aarch64.dmg`**，把 **作业扫码登记.app** 拖进「应用程序」
2. 首次打开：右键 App →「打开」（本机自建签名，未上 App Store 会提示一次）
3. 数据独立存放于 `~/Library/Application Support/com.homeworkscan.local/`（与脚本版互不影响）
   - 以前用脚本版攒了数据？菜单栏 **「作业扫码登记 → 导入旧数据（db.json）…」** 选一下项目里的 `data/db.json` 即可（导入前会自动备份现有数据）
   - 菜单里的「打开数据文件夹」可直接在 Finder 中定位数据文件
4. 第一次启动如弹出防火墙提示「是否接受传入网络连接」，点「允许」（手机扫码需要）

> 说明：App 版和脚本版数据是两份独立副本，导入一次即可；App 退出时会自动停掉内置服务并落盘。

## 一、安装（只做一次）

1. 安装 [Node.js LTS](https://nodejs.org)（电脑上装一次即可）
2. 双击 **`启动作业扫码.command`**（Mac）或 **`启动作业扫码.bat`**（Windows）
   - 首次运行会自动安装依赖（约 1 分钟）
   - 启动后会自动打开电脑端界面 `http://localhost:3000`

### 分享给 Windows 同事：免安装绿色包（推荐）

同事几乎都是 Windows、又不想折腾环境时，直接把打好的免安装包发过去：

- 产物：**`dist/作业扫码登记_Windows免安装版.zip`**（约 35MB，微信/网盘可直接发）
- 对方收到后：解压 → 双击包内 **`启动作业扫码.bat`** → 完成。**不需要装 Node.js、不需要联网**（包内自带便携版 node.exe 和全部依赖）
- 数据存在包内 `data\` 文件夹，整个文件夹拷到 U 盘/换电脑，数据跟着走；包内附 `使用说明.txt`（防火墙放行、证书信任等给老师看的要点）
- 自己重新打包：`node scripts/make-win-portable.mjs`（自动下载 Node v22 win-x64 便携版 → 装生产依赖 → 拷贝资源 → 打 zip，产物在 `dist/`）

## 二、开始使用（每学期/每天）

1. **名单**：新建班级 → 导入 Excel/CSV（需有「姓名」列，学号列可选）或手动添加
2. **二维码**：选排版（1份/人、1行/人6个、1页/人36个）→ 生成 A4 PDF → 打印贴到作业本封面右上角
   - 建议打印成不干胶防水贴，一次管一学期；谁换本子了单独勾选补打
3. **收作业**：工作台 → 选班级/科目 → 「开始收作业」→ 电脑上出现一个大二维码
4. **扫码**：手机（连同一个 WiFi）扫电脑上的码 → 首次需信任证书（见下）→ 允许摄像头 → 点「开始连续扫码」→ 镜头扫过去即可
   - **推荐姿势（实测最顺）**：点底部 🖥 开广角预览 → 手机举高 30~40cm 让一整排入镜 → **匀速缓慢横移**，一排 2 秒、整排齐录；排尾停半秒让深度识别自动补漏
   - 识别成功"叮"一声变绿；重复入镜不会重复登记；一帧里多个码会同时批量登记
   - 本子堆放要点：码朝上**单层摊开**别叠压（叠压会倾斜遮挡）；避开自己的影子
   - 底部按钮：🔦 补光灯 · 🔍＋/－ 变焦 · 🔄 换镜头 · 🖥 广角预览 · 🐞 抓帧诊断（定格分析识别问题）
   - 个别码扫不进：凑近单扫（码占画面 1/3 必出），或展开「未交 N 人」**点名字手动登记**；电脑大屏上也能点学生卡「标记已交」
   - 点「截止收集」后，再扫的码自动记为**补交**
5. **批改**：电脑端「按扫码顺序批改」——作业堆叠顺序 = 扫码顺序，键盘 <kbd>1</kbd>/<kbd>2</kbd>/<kbd>3</kbd>/<kbd>4</kbd> 依次打 A+/A/A-/不合格，<kbd>Ctrl+Z</kbd> 撤销，支持批量
6. **导出**：看板页一键复制未交名单（发家长群格式）或导出 Excel（学号/姓名/状态/顺序/时间/等级）

## 三、手机首次打开 HTTPS 提示「不安全」

浏览器规定：**摄像头只能在 HTTPS 页面使用**。本系统在电脑上自动生成了局域网自签证书，手机首次打开会提示"证书不受信任"，属正常现象，一次性放行即可：

- **iPhone (Safari)**：提示页点「显示详细信息」→「访问此网站」（部分版本输入密码确认）
- **Android (Chrome)**：点「高级」→「继续前往 …（不安全）」
- 之后正常使用；换 WiFi 导致电脑 IP 变化时，证书会自动重新生成，重做一次上面的放行即可

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 手机扫了码但打不开页面 | 确认手机和电脑连**同一个 WiFi**；部分校园网开了「设备隔离」，改用电脑开热点让手机连 |
| 点开始扫码没反应/黑屏 | 检查是否从 HTTPS 地址打开（手机上地址应以 `https://` 开头）；浏览器设置里允许该网站使用摄像头 |
| 相机一直"正在打开摄像头…" | 反复开关页面易触发浏览器相机占用卡死：完全关闭标签页重开；还不行就重启手机浏览器。App 会在 8 秒超时后自动换挡重试 |
| 个别码扫不出来 | ① 凑近单扫（码占画面 1/3）② 展开底部「未交 N 人」点名字手动登记。用 🐞 抓帧诊断可看到摄像头实际画面和各引擎识别结果 |
| 识别速度慢 | 光线充足更快；扫动**中速**（太快会运动模糊）；码与码之间保持空隙；识别引擎与分辨率显示在扫码页左上角，异常时可截图反馈 |
| 打印的码识别率低 | 打印选「实际大小/100%」不要「适应页面」（缩印会压缩静区）；码四周 4mm 内不要贴到文字或图案 |
| 扫码没声音 | 手机侧边静音键会静音网页声音，识别时画面也会变绿闪一下作为提示 |
| 换了电脑/重装系统 | 数据在 `data/db.json`，把它拷到新电脑同位置即可；该目录每次启动还会自动留最近 20 份备份（`data/backups/`） |
| 想清空全部数据 | 关闭服务后删除 `data/db.json` 再启动 |

## 五、演示模式

手机扫码页有一个「🎬 演示模式」按钮：不需要贴纸和摄像头，自动模拟扫完全班，用来向同事演示或自测整个流程。

## 六、目录说明

```
server.js               本地服务（HTTP 3000 / HTTPS 3443，端口被占用会自动顺延）
public/                 前端页面（所有依赖库已本地化在 public/vendor，离线可用）
data/db.json            全部数据（班级/名单/登记记录）
scripts/                安装与测试脚本（含 tauri-prepare.mjs 打包准备、make-win-portable.mjs Windows 免安装包）
src-tauri/              macOS App 壳（Tauri 2）：main.rs 负责拉起内置 node 服务、管理窗口与菜单
app-ui/                 App 启动等待页（服务就绪前显示）
启动作业扫码.command/.bat 双击启动（脚本版）
```

## 七、开发者

```bash
npm install            # 安装依赖
npm run vendor         # 前端库本地化（public/vendor）
npm start              # 启动服务
npm test               # 服务端 API 回归测试（需服务运行中）
node scripts/qr-hunt-test.mjs   # 一帧多码识别算法测试

# 打包 macOS App（需要 Rust 工具链 + cargo install tauri-cli）
node scripts/tauri-prepare.mjs   # 归拢资源：server.js + public + 生产依赖 + node sidecar
cargo tauri build                # 产物在 src-tauri/target/release/bundle/{macos,dmg}/
```

技术要点：服务端 Node.js + Express + ws + 自签 HTTPS（证书含局域网 IP SAN，IP 变化自动重签）；前端 Vue 3（无打包，全部本地化）；数据 data/db.json 单文件存储。macOS App 版为 Tauri 2 壳：内置 Node sidecar 子进程跑同一个 server.js，通过 stdout 握手获知实际端口，数据目录指向用户目录（`--data-dir`），退出时优雅停服。

**识别引擎（按优先级三级回退）**：
1. 浏览器原生 `BarcodeDetector`（Android Chrome 等，一帧多码最快最准）
2. **ZXing-C++ WASM**（`vendor/zxing/`，已本地化）：一次读出画面里全部二维码、逐个定位。jsQR 类解码器在"一帧多码"时会互相干扰（实测连第一个码都解不出，与码内容无关），ZXing 没有这个问题——基准测试中 33% 缩放的 10 码满帧场景从 3/10 提升到 **10/10**（`node scripts/accuracy-test.mjs` 可复现）
3. jsQR + 遮挡重扫 + 多尺度滑窗（前两者都不可用时的兜底）
