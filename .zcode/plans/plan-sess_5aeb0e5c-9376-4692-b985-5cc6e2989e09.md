## 目标

为 Windows 老师制作一个**解压即用**的绿色免安装包：不需要装 Node.js、不需要联网装依赖、不需要命令行——解压 zip，双击 `启动作业扫码.bat` 即可。

## 前置事实（已验证）

- `server.js` 纯跨平台，支持 `--data-dir` 参数指定数据目录
- 3 个运行时依赖（express、selfsigned、ws）及其传递依赖全是纯 JS，Mac 上安装的 node_modules 拷到 Windows 直接可用
- 前端库已本地化在 `public/vendor`，运行时不需要 `npm install` 和 `vendor.js`
- `server.js` 要求 Node ≥ 18

## 实施步骤

### 1. 下载 Windows 便携版 Node
从 nodejs.org 官网下载 **Node v22 LTS win-x64 zip 版**（~30MB，免安装）到 `dist/win-tmp/`（此目录进 `.gitignore`）。默认只做 x64（学校电脑几乎全是 x64；如有 ARM 需求后续可再加）。

### 2. 新建打包脚本 `scripts/make-win-portable.mjs`
生成 `dist/作业扫码登记_Windows免安装版/` 目录，包含：

```
作业扫码登记_Windows免安装版/
├── node/node.exe                    # 便携版 Node
├── server.js
├── package.json
├── public/                          # 全量拷贝（含 vendor）
├── node_modules/                    # 仅生产依赖（临时目录 npm install --omit=dev 生成，避免打包开发依赖）
├── 启动作业扫码.bat                  # 新写的便携版启动器
└── 使用说明.txt                      # 给老师的简明说明
```

**新 `.bat`**（相对现有版的改进）：
- 直接用包内 `node\node.exe` 启动，不再检测/要求系统 Node
- 不再执行 `npm install`（依赖已内置）
- 通过 `HWSCAN_DATA_DIR` 环境变量把数据指到包内 `data\`，实现**绿色便携**：整个文件夹拷到 U 盘/换电脑，数据跟着走
- 启动后自动打开浏览器，窗口保持显示服务状态，关窗即停服

**`使用说明.txt`** 内容：解压→双击→手机连同一 WiFi 扫码；首次运行 Windows 防火墙弹窗点「允许」；双击 .bat 若弹「安全警告」点「运行」；常见问题（设备隔离开热点、换电脑数据拷贝等，精简自 README）。

### 3. 打 zip
用 UTF-8 文件名编码打包成 `作业扫码登记_Windows免安装版.zip`（约 40~50MB，微信/网盘可直接发），避免中文文件名在 Windows 解压乱码。

### 4. 验证（本机可做的部分）
- 用打包出的 `node_modules`（纯生产依赖）+ 本机 Node 启动 `server.js`，跑一遍 `npm test`（API 回归测试），确认依赖树完整无缺失
- 检查 zip 内目录结构、确认无 macOS 垃圾文件（.DS_Store 等）
- Windows 上的实际运行无法在本机验证，会在使用说明里附上我这边验证不了的点，方便远程排查

### 5. 收尾
- `.gitignore` 追加 `dist/`
- README 增加一节「分享给 Windows 同事」，说明 zip 位置和分发方式
- git 提交

## 不做的事
- 不改 macOS App / Tauri 相关代码
- 不动现有 `启动作业扫码.bat`（它仍服务于「老师自己装了 Node」的场景）
- 不往 git 里提交 node.exe / 打包产物（体积大且可重新生成）
