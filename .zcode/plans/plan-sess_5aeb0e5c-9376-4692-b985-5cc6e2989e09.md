## 目标

以前端为主题化改造：**手绘漫画（默认）· 暖橙 · 毛玻璃**三套主题一键切换；**配色独立于主题**一键切换；新增「设置」页收纳外观 + 班级/名单/二维码/数据备份管理；顶栏精简为「工作台 / 历史 / 设置」。

## 架构设计（CSS 双层变量）

**主题层 `data-theme`**（管形状质感）：圆角、边框粗细、阴影风格（A 硬贴纸阴影 / B 细线平面 / C 玻璃模糊）、背景纹理（A 点点格 / B 暖纸 / C 彩色光斑+磨砂）、字体栈。默认值即手绘主题。
**配色层 `data-palette`**（只管主色）：暖橙（默认）/ 草原绿 / 晴空蓝 / 莓红 / 葡萄紫，覆盖 `--primary` 系列 token；成功/警告/危险等状态色保持通用。

组件 CSS 全部改为引用 token（保留 `--line/--bg/--card/--ink` 等旧变量名做别名，视图里的内联样式不用动）。新文件 `public/css/themes.css` 放 token + 三套主题 + 五套配色，`app.css` 只留组件层。

## 字体（已确认：内置霞鹜文楷 Lite）

- `scripts/vendor.js` 增加字体归拢：从 npm 包 `lxgw-wenkai-lite-webfont` 拷贝 Regular+Bold 的**按 unicode-range 切片的 woff2**（`npm run vendor` 后进 `public/vendor/fonts/`，浏览器按需加载实际只用几百 KB）
- 手绘主题字体栈：`"LXGW WenKai Lite", "Kaiti SC", "KaiTi", 楷体`；暖橙主题标题用系统宋体衬线栈（零体积）；毛玻璃用系统黑体

## 设置页与导航重组

- 路由：新增 `/settings/:section?`（appearance|roster|qr|data），旧 `/roster` `/qr` 重定向兼容
- **views/settings.js（新）**：设置壳 = 小节切换 + 四个分区
  1. **外观**：三张主题预览卡（CSS 缩微渲染，点击即换）+ 五色配色圆点，选择存 `localStorage`（`hw.theme`/`hw.palette`），即时生效无需刷新
  2. **班级与名单**：复用 roster-view（去掉页面包裹、拆出备份卡）
  3. **二维码打印**：复用 qr-view
  4. **数据备份**：从 roster 抽出的 data-view（导出备份/导入还原，逻辑原样）
- `app.js`：顶栏改「工作台 / 历史 / 设置（齿轮图标）」，品牌图标颜色跟配色 token
- `index.html`：`<head>` 里加无闪切换脚本（进页面前设好 `data-theme/data-palette`）+ 动态 theme-color
